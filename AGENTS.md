# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

GitHub Pages user site (`b0pof.github.io`). Лендинг дня рождения лежит **не в корне домена**, а в единственной вложенной папке репозитория — её имя случайное. Корень домена намеренно пуст. Без сборки, без зависимостей: один самодостаточный HTML с инлайновыми `<style>` и `<script>`.

Имя папки случайное намеренно: страница должна открываться только по прямой ссылке. Pages не умеет аутентификацию, поэтому защита держится на непредсказуемости пути плюс `<meta name="robots" content="noindex...">` и корневом `robots.txt`.

**Полный URL нигде в репозитории не хранится и не должен здесь появляться** — этот файл публичный, запись адреса сведёт защиту к нулю. Ссылки на страницу из корня домена не добавляй, в коммит-сообщениях путь не упоминай. Нужен адрес — смотри имя папки локально.

## Команды

```sh
open */index.html     # локальный просмотр
python3 -m http.server 8000   # если нужен http:// вместо file://
git push origin main          # деплой; Pages публикует корень main
```

Тестов и линтеров нет. Проверка — визуальная в браузере плюс `node --check` на вырезанном `<script>`.

## Ограничения формата

- Всё в одном файле. Внешние ресурсы — только Google Fonts. Нет npm, нет билд-шага, нет отдельных CSS/JS.
- Комментариев в коде нет по умолчанию (см. глобальные инструкции пользователя).
- Скрипт — один IIFE в конце `<body>`, ES5-совместимый синтаксис.
- Новую страницу заводи отдельной папкой с `index.html` — так URL остаётся без `.html`.

## Структура страницы

Секции: `#event → #place → #dress → #gifts → #wishes`, id совпадают с якорями. Добавляешь секцию — добавь ссылку **в двух местах**: `.nav-links` (десктоп) и `#menu` (мобильный оверлей).

Навигация переключается на `761px`: выше — ссылки в строку, ниже — бургер `#burger` и полноэкранное меню `#menu` (`body.locked` блокирует скролл под ним). Горизонтального скролла ссылок нет намеренно: `justify-content:flex-end` на переполненном скролл-контейнере делает начало списка недостижимым.

Обложка занимает ровно экран: `.hero` имеет `min-height:calc(100svh - var(--nav-h))` и центрирует содержимое, внизу — `.scroll-cue`, которая прячется после 60px скролла. Меняешь высоту навигации — меняй `--nav-h`, от неё считаются и высота обложки, и верх оверлея меню.

Тема: маскарад/пародия. Гость приходит в образе известной личности и весь праздничный вечер играет её манеру. Отсюда визуальный язык — занавес, маски, эффект прожектора.

## Темы

Тёмная — базовая, вся палитра объявлена на `:root`. Светлая переопределяет те же переменные в двух местах, оба нужны: `@media (prefers-color-scheme: light) :root:not([data-theme="dark"])` для системной темы и `:root[data-theme="light"]` для ручного переключателя. Новый цвет заводи переменной в **обоих** блоках, иначе он утечёт между темами.

`#theme` в навигации переключает вручную и пишет выбор в `localStorage`. JS выставляет `data-theme` (ручной выбор) и `data-effective` (`dark`/`light`, что реально показано) — по второму CSS выбирает иконку солнца или луны.

## Ключевые механики (все в финальном `<script>`)

- `TARGET` — единственный источник даты для обратного отсчёта и ссылки «Добавить в календарь». Текстовые даты в разметке (`.overline`, `.fact .v`) правятся отдельно вручную.
- `#reveal` — слой SVG-масок, видимый только под «прожектором»: `--mx/--my` двигают `mask-image`. Без точного указателя луч ходит по кругу сам, при `prefers-reduced-motion` стоит на месте.
- `.fx` — появление при скролле через `IntersectionObserver`, вешается на любой блок.
- `#wishlist` и `#form` — заглушки с `href="#"` и `aria-disabled="true"`. Появится ссылка — замени `href`, убери `aria-disabled` и соседний `.pending`; обработчик `preventDefault` перестанет срабатывать сам.

## Плейсхолдеры, которые нужно заменить перед публикацией

Дата (`3–4 октября` + `TARGET`), адрес и ссылка на карту в `#place`, ссылка на чат мероприятия, вишлист, гугл-форма.

## Дизайн-токены

Палитра, радиусы, ширина контейнера — в `:root`. Шрифты: Playfair Display (заголовки, `.serif`), Manrope (текст). Мобильные правки собраны в `@media(max-width:640px)`, отключение hover-эффектов — в `@media(hover:none)`.
